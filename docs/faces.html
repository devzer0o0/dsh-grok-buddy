表情素材参考（不是运行状态，也不是六态动画）

下面这些是 GrokBot 素材库里的预设，只提供眼型。 六态的实际动画在 src/grokbot/motion.js：blocked 是感叹号、 thinking 是三颗点、done 是彩色轨道环绕 —— 这些都不是换一张素材脸能得到的。

这张图曾经被当成「六态动画已完成」的证据，那是个错误：素材预设名（sleeping / waking / searching / curious / proud …）与运行状态无关，也与本次按参考录屏重建的动作无关。 素材现在只服务 idle / working / done 的眼睛造型； 替身动作（转动、拖尾、符号形变、轨道）全部来自动作采样器。
六态验收请看 docs/states.html 与 preview.html。
